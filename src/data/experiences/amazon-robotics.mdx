# Software Developer @ Amazon Robotics

## The Mission

Orchestrating the movement of thousands of autonomous mobile robots (AMRs) requires not just speed, but absolute reliability. As part of the **Path Planning Team**, I focused on the core algorithms that allow our robots to navigate complex, dense warehouse environments safely.

## Solving for Scale

The primary challenge at Amazon isn't finding a path for one robot—it's finding paths for 5,000 robots simultaneously while avoiding collisions and deadlocks.

*   Optimized A* search variants for grid-based warehouse maps.
*   Implemented real-time obstacle avoidance using dynamic window approaches.
*   Developed visualization tools for debugging multi-agent coordination.
